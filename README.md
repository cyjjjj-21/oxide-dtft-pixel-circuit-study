# AMOLED 像素电路：阈值补偿与双电容数据压缩

中文技术报告，比较二极管式与源跟随式阈值补偿、数据压缩及写入与补偿的时序关系，并给出八种组合的开关电容接法、优缺点和参考专利。

## 独立离线阅读

下载 `index.html` 后直接用浏览器打开即可。正文、样式、字体、公式、电路 SVG 和可下载的开关状态 JSON 均在该文件内，不需要安装软件、启动服务器或联网。参考专利链接仅在点击查阅外部原文时需要网络。

## 电路说明

报告区分已核验的专利实例与理想开关下的工程示例。八种组合不等同于八个经过完整 TFT 仿真或量产验证的像素。源到栅寄生损失、端点隔离和换接顺序均在文中说明。
